
# Mini Library Management System

A Python-based console application developed as part of the Modern Data Structures coursework.

## Project Overview

This project demonstrates the implementation and practical application of five fundamental data structure topics through a Mini Library Management System.

## Data Structures

1. Array and Dynamic Array
2. Singly and Doubly Linked List
3. Stack, Queue and Deque
4. Custom Hash Table using Chaining
5. Binary Search Tree (BST)

## Features

- Add, remove and search for books
- Borrow and return books
- Maintain borrowing history
- Manage waiting lists
- Undo the last catalogue operation
- Search and organize books using different data structures
- Compare data structure performance

## Performance Analysis

The project includes benchmarking experiments, complexity analysis and performance visualizations for the implemented data structures.

## Technologies

- Python
- Google Colab
- Matplotlib

## Project Files

- Jupyter Notebook: Implementation, tests and benchmarks
- Technical Report: Methodology, complexity analysis and results
- Presentation: Project overview and experimental findings

## How to Run

1. Download the Jupyter Notebook.
2. Open [Google Colab](https://colab.research.google.com/).
3. Upload the `.ipynb` file.
4. Run the notebook cells sequentially.
